Directional Coupler Port Schema

A 4-port directional coupler samples high-frequency signals directionally. Power entering the main Input line routes fundamentally straight to Output nodes while a designated fractional decibel component tracks onto the secondary Coupled path block structure.

Formulas & Mathematical Logic

The matrix processes numerical inputs relative to standard logarithmic boundary rules exactly:

Power Translation Scalings:
If Watts: dBm = 10 * log10(W) + 30
Coupled Signal Attenuation Logics:
Coupling = -10 * log10(P4 / P1)
Coupling Loss = -10 * log10(1 - P4 / P1)
System Network Leakage Evaluations:
Insertion Loss = -10 * log10((P2/P1) + (P3/P1) + (P4/P1))
Directivity = -10 * log10(P3 / P4)
