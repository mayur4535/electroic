Formulas

R1 = Z0 × K
R2 = Z0 × (1 / K)

Diagrams & Theory

A Bridged-Tee attenuator uses a bridge resistor across the signal path and a shunt resistor from the center node to ground. The two Z0 arms represent the matched impedance path between input and output.

This network is useful in RF signal attenuation because it can reduce signal level while keeping the input and output impedance matched.
