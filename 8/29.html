Noise Figure and Noise Temperature Diagram

Formulas Used

Noise Temperature = Reference Temperature × (10^(Noise Figure / 10) - 1)
Noise Figure = 10 × log10((Noise Temperature / Reference Temperature) + 1)

Example

Enter noise figure in dB and reference temperature in Kelvin to calculate equivalent noise temperature. Or select temperature input to convert noise temperature back to noise figure.
