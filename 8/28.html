Formulas Used

Width W = 299.792458 / (2 × f × √((εr + 1) / 2))
Effective εr = (εr + 1) / 2 + ((εr - 1) / 2) × 1 / √(1 + 12h / W)
Effective Length = 299.792458 / (2 × f × √εeff)
Length Extension ΔL = 0.412h × ((εeff + 0.3)(W/h + 0.264)) / ((εeff - 0.258)(W/h + 0.8))
Patch Length L = Effective Length - 2ΔL
