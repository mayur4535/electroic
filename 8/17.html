Formulas & Mathematical Logic

Distance Link Computation Mode (Calculates Angle & Radius Spans):
• Downtilt Angle = atan((Ht - Hr) / Distance)
• Inner Radius Footprint = (Ht - Hr) / tan(Downtilt + Beamwidth / 2)
• Outer Radius Footprint = (Ht - Hr) / tan(Downtilt - Beamwidth / 2)
Downtilt Optimization Mode (Calculates Linear Separation Range):
• Receiver Range Distance = (Ht - Hr) / tan(Downtilt)
• Inner Radius Footprint = (Ht - Hr) / tan(Downtilt - Beamwidth / 2)
• Outer Radius Footprint = (Ht - Hr) / tan(Downtilt + Beamwidth / 2)

The system leverages basic trigonometric angular relationships to map signal dispersion boundaries down onto targeted terrestrial geographic matrices safely.
