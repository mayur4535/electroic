N-Way Power Divider Diagram

Formulas

Split Loss = -10 × log10(1 / N)
Split Loss = 10 × log10(N)
Total Loss = Split Loss + Insertion Loss

Diagrams & Theory

An N-way power divider splits one RF input signal into multiple output ports. The ideal split loss increases as the number of output ports increases.

Real power dividers also include extra insertion loss, connector loss, PCB loss, and frequency-dependent loss. Add that value as extra loss in dB.

Example

Input Example

No. of Ports: 4
Insertion Loss: 0.5 dB

Output

Ideal split loss is 6.0206 dB. Total loss becomes 6.5206 dB after adding 0.5 dB insertion loss.
