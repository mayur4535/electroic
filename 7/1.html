Diagrams & Theory

An adjustable voltage regulator uses a feedback resistor divider. R1 connects from output to adjust node, while R2 connects from adjust node to ground.

Formulas & Mathematical Logic

Original formula preserved: R2 = (Output Voltage - Reference Voltage) × R1 / Reference Voltage
In symbols: R2 = (Vo - Vr) × R1 / Vr
R1 input unit is converted internally to Ω. R2 output is converted only for display using the R2 result selector.

This adjustable voltage regulator resistor divider calculator keeps the original formula behavior, including negative R2 when output voltage is lower than reference voltage.
