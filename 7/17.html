Formulas & Mathematical Logic

If input is Peak Voltage: Vrms = Vp / sqrt(2).
If input is Peak-to-Peak Voltage: Vrms = Vpp / (2 × sqrt(2)).
If input is Average Voltage: Vrms = Vavg × PI / (2 × sqrt(2)).
Unit conversion: V = value, mV = value × 0.001, kV = value × 1000.
