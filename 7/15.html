Diagrams & Theory

Peak voltage is measured from the zero axis to the maximum waveform amplitude. Peak-to-peak voltage is measured from the positive peak to the negative peak.

Formulas & Mathematical Logic

Step 1: Convert input value to volts using selected input unit: V = value, mV = value × 0.001, kV = value × 1000.
If input is Peak Voltage: Vp = input voltage.
If input is RMS Voltage: Vp = Vrms × sqrt(2).
If input is Average Voltage: Vp-p = Vavg × PI, therefore Vp = Vavg × PI / 2.
Peak-to-Peak Voltage: Vp-p = 2 × Vp.

About This Calculator

Convert RMS, average or peak voltage into peak and peak-to-peak voltage.

The CalcBoy Peak Voltage Calculator converts known peak, RMS or average voltage into peak voltage and peak-to-peak voltage with V, mV and kV input units.

Peak voltage is the highest value a waveform reaches from the zero reference line. Peak-to-peak voltage is the full swing from the positive peak to the negative peak. These values matter in oscilloscope measurements, amplifier headroom, transformer insulation, rectifier diode rating, capacitor voltage rating and AC waveform analysis.

Many meters show RMS voltage, while oscilloscopes often show peak or peak-to-peak voltage. For a sine wave, RMS voltage and peak voltage are connected by the square-root-of-two relationship. Average voltage is also used in rectified waveform calculations, so this calculator includes an average-to-peak conversion based on the original source logic.

Use this tool for signal generator setup, inverter output checks, mains waveform study, transformer secondary analysis, audio amplifier voltage swing, rectifier design and high-voltage waveform conversion. Always remember that these formulas assume ideal sine-wave relationships; distorted waveforms can produce different peak, RMS and average ratios.

Frequently Asked Questions

What is peak voltage?

Peak voltage is the maximum voltage level measured from the zero reference line to the waveform peak.

What is peak-to-peak voltage?

Peak-to-peak voltage is the full voltage swing from the positive peak to the negative peak.

How do I convert RMS to peak voltage?

For a sine wave, peak voltage equals RMS voltage multiplied by sqrt(2).

How do I convert peak to peak-to-peak?

For a symmetrical waveform, peak-to-peak voltage equals 2 × peak voltage.

Why is peak voltage higher than RMS voltage?

RMS is an effective heating value, while peak voltage is the highest instantaneous waveform value.

Can this calculator handle kV?

Yes. Select kV as the input unit, and the calculator converts it internally to volts.
