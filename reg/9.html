Diagrams & Theory

A resistor ratio or voltage divider uses two resistors to convert input voltage into a predictable output voltage. E-series matching helps reduce ratio error using real-world resistor values.

Formulas & Mathematical Logic

Direct resistor ratio: Ratio = R1 / R2
Voltage divider ratio: Vout / Vin = R2 / (R1 + R2)
Equivalent divider resistor ratio used by search: R1 / R2 = ratio / (1 - ratio)
