Formulas & Mathematical Logic

Wire core allocations inside DIN 47100 standard cables follow a repetitive mathematical sequence of color patterns.

Core to Pair formula: Pair Number = Math.ceil(Core_Number / 2)

About This Calculator

Instantly identify standard DIN 47100 cable core color codes and pair assignments.

The CalcBoy DIN 47100 Cable Color Code Finder maps telecommunications and control wire cores securely.

DIN 47100 is a standard German industrial convention used to specify color codes for multi-conductor telecom, control, and signal cables. In electronic designs, control systems, and machinery wiring, a single cable can bundle up to 61 individual conductors. Splicing these cables during machine repairs or system installations requires identifying each core correctly to prevent short circuits and system damage.

To keep multi-core cables manageable, conductors are twisted together in pairs, helping to cancel out electromagnetic interference and signal coupling. The DIN 47100 standard establishes a clear, repeating sequence of base colors, dual stripes, and triple stripes to let technicians trace wires up to 60 cores (30 pairs) and one single end core.

This dynamic tool makes identifying these wires fast and simple. Users can select any core number to instantly find its assigned pair, official colors, shortform, and a live visual preview of its striped pattern, avoiding manual lookups in dry catalog sheets.

Frequently Asked Questions

1. What is the DIN 47100 standard?

DIN 47100 is a German industrial standard that defines the color sequence for multi-conductor cables used in telecommunication, signal transmission, and control system systems.

2. How are the wires paired in a DIN 47100 cable?

Cores are twisted together in sequential pairs. For example, Core 1 (White) and Core 2 (Brown) form Pair 1. This paired structure helps cancel out magnetic fields and reduce signal coupling.

3. What do multi-striped wire colors mean?

For cables with more than 10 cores, solid colors are exhausted. The standard uses a base color with secondary stripes (e.g. Grey-Pink for Core 11) or triple stripes with black (e.g. White-Brown-Black for Core 45).

4. Why is Core 61 listed as 'Single' instead of a pair?

A standard DIN 47100 layout supports up to 30 twisted pairs (60 cores). Core 61 is added as an unpaired, single conductor (Black-White) running along the center or outer layer of the bundle.

5. Is DIN 47100 identical to the Western Electric telecom code?

No. DIN 47100 is a European standard and uses a different color sequence than the Western Electric standard (which is common in North American telephone and network installations).

6. How can I identify striped wires on real cable cores?

Striped wires typically have a solid base jacket color with thin, spiral or longitudinal bands of the secondary stripe color printed along the wire length.
