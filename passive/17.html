Formulas & Mathematical Logic

Reactance = 2πfL
Inductance = X / (2πf)
Admittance = 1000 / Reactance
Original frequency logic is preserved: GHz uses multiplier 1, MHz uses multiplier 0.001.

Step-by-Step Example

Example: L = 10 nH and frequency = 2 GHz.
Reactance = 2 × π × 2 × 10 = 125.663706 Ω.
Admittance = 1000 / 125.663706 = 7.958 m-m.

About This Calculator

Fast RF inductance, reactance and admittance conversion.

This CalcBoy calculator helps convert between inductor value and frequency-dependent reactance using a lightweight RF design workflow.

Inductive reactance changes with frequency, so the same inductor can behave very differently at low frequency, RF frequency and microwave frequency. A small nH inductor may look almost like a wire at low frequency, but it can create meaningful impedance at GHz frequencies. This Inductance & Reactance & Admittance Calculator is useful when checking RF matching networks, PCB inductors, bias chokes, impedance paths, and quick high-frequency design estimates.

Frequently Asked Questions

What is inductive reactance?

Inductive reactance is the opposition an inductor provides to AC current. It increases as frequency increases.

What formula is used?

The calculator uses Reactance = 2πfL and Inductance = X / (2πf), preserving the original calculator logic.

Why is inductance entered in nH?

nH is common in RF and microwave circuits where inductors are often very small.

Can I use MHz instead of GHz?

Yes. Select MHz in the frequency unit selector. The code converts it using the original multiplier.

What is admittance here?

Admittance is calculated as 1000 divided by reactance in the original calculator format.

Does this include parasitic capacitance?

No. This is a simplified ideal inductor calculation and does not include self-resonant frequency or parasitic effects.

Is this useful for RF matching?

Yes, it is useful for quick estimates in RF matching and impedance network design.

Why does reactance increase with frequency?

Because inductive reactance is directly proportional to frequency and inductance.
