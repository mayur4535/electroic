Formulas & Mathematical Logic

Ω = 2π × (1 − cos(θ × π / 360))
Luminous Flux = Intensity × Ω / 1000
Intensity is entered in mcd, so it is divided by 1000 to convert millicandela into candela before getting lumens.

Step-by-Step Example

Example: Intensity = 12000 mcd and beam angle = 30°.
Ω = 2π × (1 − cos(30 × π / 360)) = 0.214094 sr.
Lumens = 12000 × 0.214094 / 1000 = 2.569128 lm.

About This Calculator

Convert LED mcd rating into usable lumen output.

This MCD to Lumens Converter helps compare LEDs more realistically by including beam angle and solid angle.

Many LED datasheets list brightness in mcd, but lighting projects often need lumens. Millicandela describes luminous intensity in one direction, while lumens describe total luminous flux. That means a narrow-beam LED and a wide-beam LED can have the same mcd rating but very different lumen output. This calculator uses beam angle to estimate the solid angle and then converts mcd into lumens.

Frequently Asked Questions

What is mcd?

mcd means millicandela. It is one-thousandth of a candela and measures directional luminous intensity.

What is a lumen?

A lumen measures total visible light output from a source.

How does beam angle affect lumens?

A wider beam covers a larger solid angle, so the same mcd value can convert into more lumens.

Why can two LEDs with the same mcd have different lumens?

Because beam angle changes how much total light is spread into space.

What is solid angle?

Solid angle is a 3D angle measured in steradians. It describes how wide the light cone is.

Is mcd the same as candela?

No. 1000 mcd equals 1 candela.

Can I compare LEDs using lumens?

Yes. Lumens are better for comparing total light output.

Does beam angle change perceived brightness?

Yes. Narrow beams can look brighter in one direction, while wide beams spread light over more area.
