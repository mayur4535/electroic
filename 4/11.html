About This Calculator

Estimate electrical wire size for voltage-drop based cable planning.

The CalcBoy Wire Size Calculator helps estimate AWG or MCM conductor size from voltage, phase, material, current and cable distance.

Wire size selection matters because every conductor has resistance. When current flows through a long wire, some voltage is lost before it reaches the load. If the wire is undersized, motors may run hot, pumps may start weakly, lighting may dim, and sensitive equipment may behave poorly. This calculator gives a quick planning estimate using voltage drop logic and a built-in AWG/MCM lookup table.

Copper and aluminium conductors behave differently. Copper normally needs a smaller size for the same current and distance because it has lower resistance. Aluminium can be useful for feeders and long cable runs, but the required conductor size is usually larger. This calculator lets you switch material, phase, voltage, current and distance quickly, so you can compare practical wiring options during early design.

Best UseEarly wire sizing for branch circuits, feeders, motors, pumps and inverter wiring.
Material ChoiceCopper and aluminium use different K constants in the calculation.
Distance EffectLonger runs increase required wire size because voltage drop increases.
Safety ReminderFinal conductor selection must follow local electrical code and breaker rules.
Tip: Voltage drop calculation is only one part of wire sizing. Always verify ampacity, insulation rating, conduit fill, temperature correction, grounding and local electrical code before installation.

Frequently Asked Questions

What does this wire size calculator calculate?

It estimates the required AWG or MCM wire size using voltage, phase, conductor material, current and distance.

Why does distance affect wire size?

Longer wire runs have more resistance, which increases voltage drop. A larger conductor helps reduce that voltage loss.

Why does aluminium need a larger wire size than copper?

Aluminium has higher resistance than copper, so it often needs a larger conductor for the same current and distance.

Can I use this for three phase wiring?

Yes. Select Three in the phase dropdown to use the three-phase multiplier in the original calculation logic.

Is the result enough for final installation?

No. This is a planning estimate. Final wiring must be checked against local electrical code, breaker size, insulation type and installation conditions.

What is AWG?

AWG means American Wire Gauge, a standard used for naming conductor sizes.

What is MCM?

MCM, also called kcmil, is used for larger wire sizes and means thousands of circular mils.
