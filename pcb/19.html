Diagrams & Theory

An embedded microstrip trace sits inside the dielectric below the top surface and above the bottom reference plane. H1 and H2 define the trace position inside the PCB stackup.

Formulas & Mathematical Logic

The calculator preserves the supplied embedded microstrip JavaScript formula and unit multipliers.
It first calculates microstrip impedance using H1, then applies embedded-height correction using H2 - H1.
If H2 is lower than H1, correction becomes zero as in the original source logic.
