Diagrams & Theory

An asymmetric stripline has a trace located closer to one reference plane than the other. Because H1 and H2 are different, impedance shifts compared with a symmetric stripline.

Formulas & Mathematical Logic

The calculator preserves the supplied asymmetric stripline impedance JavaScript logic and unit multipliers.
It first evaluates an equivalent symmetric stripline using average height, then applies correction based on H1, H2, trace thickness and trace width.
Final impedance is scaled by dielectric constant using the original formula.
