Diagrams & Theory

A symmetric stripline has one conductor centered between two reference planes. The electric field is contained mostly inside the dielectric, making it useful for controlled RF and high-speed PCB routing. Because both reference planes surround the trace, stripline routing can provide better shielding than a surface microstrip trace.

About This Calculator

Estimate controlled impedance for centered stripline PCB routing.

The CalcBoy Symmetric Stripline Impedance Calculator calculates characteristic impedance from trace thickness, substrate height, trace width and dielectric constant.

Symmetric stripline is a transmission line structure where a copper trace is embedded between two reference planes, usually ground planes, with roughly equal dielectric spacing above and below the conductor. This geometry is widely used in RF PCB design, microwave routing, high-speed digital boards and controlled-impedance multilayer layouts.

Unlike a surface microstrip, most of the electric field in a stripline is contained inside the dielectric material. This can improve shielding and reduce radiation, but the impedance depends strongly on the PCB stack-up. Trace width, copper thickness, dielectric constant and reference-plane spacing must be selected carefully when targeting common values such as 50 ohms or 75 ohms.

This calculator is useful for RF engineers, PCB designers, embedded hardware designers and repair engineers who want a quick estimate before checking the final stack-up with a PCB manufacturer. For production work, always confirm impedance with the board house because real copper plating, dielectric tolerance, glass weave and lamination process can shift the final value.

Frequently Asked Questions

What is symmetric stripline impedance?

It is the characteristic impedance of a centered conductor embedded between two reference planes in a multilayer PCB.

Why is stripline used in RF PCB design?

Stripline keeps most of the field inside the dielectric, which can reduce radiation and provide better shielding than surface routing.

What affects stripline impedance?

Trace width, copper thickness, dielectric constant and distance between reference planes all affect impedance.

Does wider trace reduce impedance?

Yes. Increasing trace width generally lowers characteristic impedance.

Can I use this for 50 ohm PCB routing?

Yes, it can estimate geometry for 50 ohm stripline routing, but final values should be confirmed with PCB manufacturer stack-up data.

Is this the same as microstrip impedance?

No. Microstrip is on an outer layer over a reference plane, while stripline is embedded between two reference planes.
